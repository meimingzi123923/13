# 02 · 技术选型

## 1. 语言与框架

| 项 | 选择 | 理由 |
|----|------|------|
| 开发语言 | **Kotlin** | 原生性能、协程、空安全 |
| UI | **Jetpack Compose** | 声明式、精简、主题统一 |
| 架构 | MVVM + Repository | 标准、易测 |
| 异步 | Kotlin Coroutines + Flow | 终端输出流式渲染 |
| 构建 | Gradle KTS | 现代写法 |

> 备选：Flutter（跨端但调用 PTY/Root 要写插件）；不推荐，原生更贴合系统能力。

## 2. 代码编辑器内核（三选一）

| 方案 | 优点 | 缺点 | 结论 |
|------|------|------|------|
| **Sora Editor** | Android 原生、高性能、支持 TextMate 语法、Rosemoe 出品、有 LSP 接入 | 生态较新 | ✅ 主选（默认编辑器） |
| CodeEditor (by qinci) | 轻量、上手快 | 功能少 | 备选（低配机） |
| Monaco Editor (WebView) | 功能最全、生态最大 | WebView 内存高、与原生互操作绕 | ✅ 作为「高级模式」可选加载 |

**策略**：默认 Sora Editor；检测到设备内存 ≥ 6G 时，提供「Monaco 模式」开关。

语法高亮来源：`TextMate .tmLanguage`（VSCode 同源），实现与 VSCode 视觉一致。

## 3. 终端与运行时

| 需求 | 方案 |
|------|------|
| 真实终端 | **JNI PTY**（参考 Termux 的 `libtermux` / `pty` 实现） |
| 完整 Linux | **proot-distro** 安装 Ubuntu/Alpine rootfs（无需 Root） |
| Root 级 shell | **libsu**（topjohnwu）→ `su -c`；无 Root 时用 **Shizuku** 回退 |
| 语言运行时 | Python(Chaquopy 或 proot)、Node.js、Go、Rust、OpenJDK、clang |

> 说明：Chaquopy 把 CPython 直接编进 APK，启动快、无需 proot；
> 但生态包需匹配 ABI。**推荐：Python 用 Chaquopy 内置，重型工具链放 proot。**

## 4. 编译与构建

| 语言 | 工具链 | 产物 |
|------|--------|------|
| C/C++ | clang + NDK 工具链 | ELF 可执行 / .so |
| Java | javac + d8 + aapt2 | .class → .dex → .apk |
| Kotlin | kotlinc（JVM） | .jar |
| Go | go build (linux/arm64) | 静态二进制 |
| Rust | cargo + rustup (aarch64-linux) | 二进制 |
| Python | 解释执行（无需编译） | — |
| 前端 | esbuild / vite（proot 内 npm） | bundle |

**统一任务系统**：`tasks.json` 描述 build / run / clean，由 `TaskRunner` 在 proot 里执行，输出回传终端面板。

## 5. 插件系统

| 类型 | 技术 | 能力边界 |
|------|------|----------|
| **JS 插件** | QuickJS（嵌入式，沙箱） | 改主题、加命令、加菜单、调 Host API；不能碰私有内存外的东西 |
| **JVM 插件** | `DexClassLoader` 加载 `.jar/.dex` | 完整原生能力，需声明权限；装时校验签名 |
| 插件清单 | `plugin.json` | 名称/版本/入口/权限/贡献点 |

选择 QuickJS 而非 V8：体积小（~200KB）、无 JIT 适合移动端、沙箱好做。

## 6. Root 相关

- **libsu**：主流 Root 封装，提供 `Shell`、`RootService`（常驻 root 服务，减少重复弹窗）。
- 无 Root：**Shizuku** 让 App 以 shell 身份执行部分特权命令（无线 ADB 激活）。
- 权限清单：文件系统、包管理、系统设置、网络、挂载。全部**按需申请 + 明示用途**。


## 8. 最低配置与体积预估

| 项 | 目标 |
|----|------|
| minSdk | 26 (Android 8.0) |
| targetSdk | 最新 |
| APK 基础体积 | 约 30–45 MB（不含 proot 镜像） |
| Ubuntu rootfs（可选下载） | 约 60–120 MB |
| 运行内存 | 编辑 200MB 起；proot 另计 |
