# 05 · 插件系统规范

## 1. 双轨插件

| 类型 | 文件 | 引擎 | 适用 |
|------|------|------|------|
| JS 插件 | `main.js` + `plugin.json` | QuickJS 沙箱 | 轻量：命令、主题、菜单、格式化 |
| JVM 插件 | `plugin.jar` / `classes.dex` | DexClassLoader | 重型：深度系统集成、Root 相关 |

**默认推荐 JS 插件**：安全、跨版本、无需重新编译。

## 2. 插件包结构

```
my-plugin.zip
├── plugin.json        # 清单（必需）
├── main.js            # JS 入口
├── icon.png           # 图标（可选）
├── themes/            # 主题（可选）
│   └── my-theme.json
└── README.md
```

## 3. plugin.json 清单

```json
{
  "id": "com.example.formatter",
  "name": "代码格式化",
  "version": "0.9.0",
  "author": "someone",
  "description": "支持 Python/JS/C 的代码格式化",
  "type": "js",
  "main": "main.js",
  "engines": { "pcs": ">=1.0.0" },
  "permissions": ["fs.read", "fs.write", "editor.read"],
  "contributes": {
    "commands": [
      { "id": "formatter.run", "title": "格式化当前文件" }
    ],
    "menus": [
      { "command": "formatter.run", "when": "editorContext", "group": "edit" }
    ],
    "languages": ["python", "javascript", "c"]
  }
}
```

## 4. JS 插件 API（Host API）

插件通过全局对象 `pcs` 调用宿主能力，全部为 Promise/同步混合风格：

```js
// 生命周期
export function activate(ctx) {
  ctx.log("插件已激活");
}
export function deactivate() { }

// 编辑器
pcs.editor.getText()            // 当前文件全文
pcs.editor.setText(str)
pcs.editor.getSelection()       // {start, end, text}
pcs.editor.replaceSelection(str)
pcs.editor.getFilePath()

// 命令与 UI
pcs.commands.register(id, fn)
pcs.ui.showToast(msg)
pcs.ui.showInput({title, value}) // 返回用户输入
pcs.ui.showMessage({type:"info", text})

// 文件（受权限约束）
pcs.fs.read(path)
pcs.fs.write(path, content)
pcs.fs.list(dir)

// 终端
pcs.terminal.run(cmd)           // 在本机原生执行，返回 {stdout, stderr, code}

// 主题
pcs.theme.register({name, colors})
pcs.theme.setActive(name)

// 存储（插件私有 KV）
pcs.storage.set(key, value)
pcs.storage.get(key)
```

## 5. 权限模型

| 权限 | 含义 |
|------|------|
| `fs.read` / `fs.write` | 读写工作区文件 |
| `fs.root` | 读写工作区外文件（需 Root/授权） |
| `editor.read` / `editor.write` | 读写编辑器内容 |
| `terminal.run` | 执行终端命令（危险，每次提示） |
| `root.exec` | 执行 Root 命令（最高危，需二次确认） |
| `network` | 发起网络请求 |

首次使用某权限时弹窗授权并**记录**；在插件面板可查看/撤销。

## 6. 沙箱与安全

- QuickJS 独立运行时，**无 `eval` 逃逸到宿主**、无直接文件系统句柄。
- 每个插件调用有**超时**（默认 3s）与**内存上限**（默认 32MB）。
- 插件崩溃只终止自身线程，主程序不受影响。
- JVM 插件安装时校验签名；未签名仅允许「开发者模式」装载。
- 危险 API（`terminal.run`、`root.exec`）调用前高亮提示命令原文。

## 7. 示例插件：一键格式化

```js
export function activate(ctx) {
  pcs.commands.register("formatter.run", async () => {
    const file = pcs.editor.getFilePath();
    const text = pcs.editor.getText();
    pcs.fs.write("/tmp/_fmt_input", text);
    const r = await pcs.terminal.run(
      `cd "${file}" 2>/dev/null; python3 -m black - <<'EOF'\n${text}\nEOF`
    );
    if (r.code === 0) {
      pcs.editor.setText(r.stdout);
      pcs.ui.showToast("已格式化");
    } else {
      pcs.ui.showMessage({ type: "error", text: r.stderr });
    }
  });
}
```

## 8. 插件市场

- 官方维护 `index.json`，托管于 CDN/GitHub：
  ```json
  {
    "plugins": [
      { "id": "com.example.formatter", "name": "代码格式化",
        "version": "0.9.0", "url": "https://.../formatter.zip",
        "sha256": "…", "downloads": 1200 }
    ]
  }
  ```
- 安装时校验 sha256，防篡改。
- 支持离线从本地 `.zip` 安装。

## 9. 与 VSCode 的关系

- 语法/主题尽量复用 VSCode 的 `tmLanguage` / `tmTheme` / 主题 JSON，做到「拿来即用」。
- 但**不直接兼容 VSCode JS 插件 API**（Node 依赖太重），而是提供更轻的 `pcs.*` API。
- 长期可做一个「API 适配层」，把常用 VSCode API 映射到 `pcs.*`。
