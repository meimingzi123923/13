# 03 · 功能模块与里程碑

## 1. 模块拆解

### M1 编辑器模块（EditorService）
- 多标签打开/关闭/切换
- TextMate 语法高亮（50+ 语言）
- 自动缩进、括号配对、代码折叠
- 行号、当前行高亮、minimap（可选）
- 查找/替换、跳转行
- 自动保存 / 撤销栈

### M2 文件与工作区（FSService）
- 文件树（新建/重命名/删除/移动）
- 工作区 = 一个根目录
- 文件搜索（文件名 + 内容）
- 与系统分享/打开方式打通

### M3 终端（TerminalService）
- 多会话 Tab、可复制粘贴
- 支持 `Ctrl`/`Alt`/`Esc` 虚拟按键
- 触控滚动、字号缩放
- proot 进入/退出、root shell

### M4 构建与运行（BuildRunService）
- 读取 `.pcs/run.json` 一键运行（F5 概念）
- 构建任务（`tasks.json`）后台执行
- 输出面板：stdout/stderr 分色
- 错误行可点击跳到编辑器对应行

### M5 包与依赖（PackageManager）
- 图形化展示已安装 pip/npm 包
- 一键安装/卸载（调用终端）
- 依赖体积/版本查看

### M6 插件（PluginManager）
- 插件市场（在线 index.json）+ 本地安装（.zip/.js/.jar）
- 启用/禁用/卸载
- 插件贡献点：命令、右键菜单、状态栏项、主题、侧栏面板
- 权限声明与授权

### M7 Root（RootService）
- Root 状态检测（未 Root / Root / Shizuku）
- 权限请求与常驻服务
- 常用 Root 操作模板：挂载 rw、改 hosts、杀进程、查看系统文件

### M8 设置与主题
- 主题：深色/浅色 + 自定义配色（导入 VSCode 主题 JSON）
- 字体、字号、Tab 宽度、键位
- 云端同步（可选，WebDAV/Git）

## 2. 里程碑（建议 8 个冲刺）

| 阶段 | 交付 | 验收标准 |
|------|------|----------|
| **S1 骨架** | 空壳 App + Compose 导航 + 编辑器只读打开文件 | 能打开并高亮一个 .py |
| **S2 编辑** | 多标签、保存、查找替换 | 能编辑并保存文件 |
| **S3 终端** | 内嵌 PTY，能跑 `echo` / `ls` | 终端可用 |
| **S4 运行** | run.json + 运行 Python/Node | 一键运行并看到输出 |
| **S5 工具链** | proot Ubuntu + gcc/go/cargo | 能编译 C 并运行 |
| **S6 插件** | JS 插件加载 + 一个示例插件 | 安装示例插件生效 |
| **S7 Root** | libsu 集成 + 权限面板 | 能执行 `su -c id` |
| **S8 打磨** | 主题、性能、APK 体积、错误处理 | 稳定可用，界面精简达标 |

## 3. 关键用户故事

- 作为学生，我打开 App 能 3 秒内新建 `.py` 并运行看到结果。
- 作为开发者，我能在终端里 `pip install requests` 后直接 import。
- 作为玩机用户，我能开 Root 模式改 `/system/etc/hosts`。
- 作为进阶用户，我装一个「代码格式化」插件，右键就能用。

## 4. 非功能需求

| 类别 | 指标 |
|------|------|
| 冷启动 | < 2s（不含运行时初始化） |
| 打开 1MB 文件 | < 500ms |
| 终端回显延迟 | < 50ms |
| 崩溃率 | < 0.5% |
| 无障碍 | 支持大字号、TalkBack 基础朗读 |

## 5. 风险与对策

| 风险 | 对策 |
|------|------|
| 低端机内存不足 | 编辑器用原生 Sora；proot 按需启停 |
| Root 弹窗频繁 | 用 libsu RootService 常驻一次授权 |
| 工具链体积大 | 拆为可选下载模块，按语言按需拉取 |
| 包管理网络慢 | 内置镜像源切换（清华/阿里） |
| 各厂商杀后台 | 前台服务 + 引导用户加白名单 |
