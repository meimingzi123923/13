# 04 · UI 设计

设计关键词：**精简 · 整洁 · 信息克制 · 拇指可达**。

## 1. 设计语言

- 配色：深色为主（开发者友好），Primary 用低饱和蓝紫 `#6C8CFF`，背景 `#0F1115`。
- 圆角 12dp，分割线极细（0.5dp，色 `#FFFFFF10`）。
- 图标：线性图标（Material Symbols），线宽统一 1.5。
- 字体：等宽 `JetBrains Mono`（编辑器）+ 系统字体（UI）。
- 动效：仅保留面板滑入/滑出（200ms）与状态切换，不做多余动画。

## 2. 主界面布局（默认态）

```
┌───────────────────────────────────────────────┐
│  ☰   main.py ×   utils.py ×            ⋮  ▶  │  ← 顶部：标签 + 运行
├───────────────────────────────────────────────┤
│  1  import os                                 │
│  2  def main():                               │
│  3      print("Hello")                        │
│  4                                            │
│                                               │
│                    (编辑器，占满)              │
│                                               │
│                                               │
├───────────────────────────────────────────────┤
│  Python 3.12 · UTF-8 · Ln 3, Col 5 ·  ✓ 保存  │  ← 状态栏（一行）
└───────────────────────────────────────────────┘
```

**默认只显示：顶部标签栏 + 编辑器 + 底部状态栏**，最干净。

## 3. 左侧文件树（抽屉式，可滑出）

```
┌──────────────┐
│ 📁 my-project│
│  📁 src      │
│   🐍 main.py │
│   🐍 utils.py│
│  📄 README   │
│              │
│ ＋   ↻   ⌕  │  ← 新建/刷新/搜索
└──────────────┘
```
- 从左侧边缘右滑唤出，或点 ☰。
- 宽度 280dp，半透明遮罩，不挤压编辑器（overlay）。

## 4. 底部终端面板（上滑唤出）

```
┌───────────────────────────────────────────────┐
│  终端  ⨯           bash ▾        ＋  ⌨  🗑     │
├───────────────────────────────────────────────┤
│  ~/my-project$ python3 main.py                │
│  Hello                                        │
│  ~/my-project$ █                              │
├───────────────────────────────────────────────┤
│  Esc  Tab  Ctrl  Alt  ↑  ↓  ←  →   |   /  -   │  ← 虚拟功能键
└───────────────────────────────────────────────┘
```
- 高度可拖拽（30% / 60% / 全屏三档吸附）。
- 虚拟键解决手机无物理键盘问题。

## 5. 运行/输出面板

运行后从底部弹出，与终端同一区域：
- 绿色 = 正常输出，红色 = 错误，灰色 = 系统日志。
- 错误行格式 `main.py:3: error: ...` → **可点击跳转**。

## 6. 侧边活动栏（Activity Bar，极简）

右侧悬浮 4 个图标（点击展开对应面板）：
```
┌──┐
│📄│ 文件
│⌕ │ 搜索
│🧩│ 插件
│⚙ │ 设置
└──┘
```
也可放左侧；用户可在设置里选左右手。


## 8. 设置页

分组：外观 / 编辑器 / 终端 / 运行时 / Root / 同步 / 关于。
- 外观：主题、字号、行高、字体。
- 编辑器：Tab 宽、自动保存、补全开关、Vim 键位（可选）。
- 运行时：安装/卸载语言工具链、镜像源。
- Root：状态、授权、常驻服务开关。

## 9. 交互规范

| 操作 | 手势 |
|------|------|
| 唤出文件树 | 左缘右滑 / 点 ☰ |
| 唤出终端 | 双指上滑 / 点状态栏终端图标 |
| 运行 | 顶部 ▶ 或 音量键组合（可选） |
| 保存 | 自动保存 + 手动 Ctrl+S 概念（顶部对勾） |
| 切换标签 | 标签横滑 / 长按标签列表 |
| 命令面板 | 长按搜索键，输入命令（类 VSCode Ctrl+Shift+P） |

## 10. 精简性保障

1. 任何时刻屏幕上最多 3 个区域（标签栏 / 主体 / 状态栏）。
2. 侧栏与终端都是 overlay，不永久占位。
3. 状态栏只显示「语言 · 编码 · 光标 · 保存态」四项，可点击展开更多。
4. 无广告、无 Banner、无强制登录。
