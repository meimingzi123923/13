# PocketCode Studio 使用指南（用户版）

> 本篇是**给使用者看的教程**，不是开发文档。
> 目标：第一次打开 App，也能 5 分钟上手。

---

## 0. 这是什么

PocketCode Studio 是一个跑在 Android 手机上的「口袋版 VSCode」。
你在手机上就能：**写代码 → 保存 → 一键运行 → 看终端输出 → 用 Root 跑系统命令**。

---

## 1. 界面速览

打开 App 后，界面从上到下只有 4 个区域：

```
┌─────────────────────────────────────────┐
│ 📂  💾  ▶  🖥   ❓                    🔒Root │  ← ① 顶部工具条
├─────────────────────────────────────────┤
│ ● main.py ✕ │ ● test.js ✕ │              │  ← ② 标签栏（打开的文件）
├─────────────────────────────────────────┤
│                                          │
│           代码编辑区                      │  ← ③ 编辑区（主区域）
│                                          │
├─────────────────────────────────────────┤
│ 就绪                              PY      │  ← ④ 状态栏
└─────────────────────────────────────────┘
```

### 顶部工具条 4 个按钮（从左到右）

| 图标 | 名称 | 作用 |
|------|------|------|
| 📂 FolderOpen | **文件树** | 唤出左侧抽屉，列出工作区所有文件，点一下即打开 |
| 💾 Save | **保存** | 把当前标签的内容写回磁盘（标签上的 ● 随之消失） |
| ▶ PlayArrow | **运行** | 按文件后缀自动挑运行命令，并在终端里执行 |
| 🖥 Terminal | **终端** | 唤出底部终端面板，可手动敲命令 |
| ❓ Help | **使用帮助** | 再次弹出本引导 |
| 🔒 Root | **Root 指示** | 仅在已授权 Root 时显示，表示可执行系统级命令 |

> 标签上的 `●` 表示「有未保存修改」。点标签右侧的 `✕` 关闭文件。

## 2. 五分钟上手

### ① 打开 / 新建文件
- 点顶部 **📂** → 弹出「工作区」列表 → 点任意文件打开。
- 工作区固定路径：`/sdcard/PocketCodeStudio/workspaces`。
  你可以用手机自带的文件管理器，往这个目录里丢 `.py` / `.js` / `.c` 等文件，再回到 App 点 📂 就能看到。
- 如果列表显示「（空）」，说明工作区还没有文件 —— 用文件管理器放一个进去即可。

### ② 编辑
- 直接在中间编辑区打字即可（等宽字体）。
- 改完状态栏会显示「未保存」，记得点 **💾**。

### ③ 运行
- 点 **▶**，App 会：
  1. 按当前文件后缀读取/生成运行命令；
  2. 自动打开底部终端；
  3. 在终端里执行并把输出实时显示出来。
- 命令规则（自动判断，无需配置）：

| 你的文件 | 自动执行的命令 |
|----------|----------------|
| `*.py`           | `python3 文件` |
| `*.js` / `*.mjs` | `node 文件` |
| `*.ts`           | `npx tsx 文件` |
| `*.c`            | `gcc 文件 -o a.out && ./a.out` |
| `*.cpp`          | `g++ 文件 -o a.out && ./a.out` |
| `*.go`           | `go run 文件` |
| `*.rs`           | `cargo run` |
| `*.java`         | `javac 文件 && java Main` |
| 其它             | `cat 文件`（仅预览） |

> ⚠️ 能否跑起来，取决于**运行时是否已装在设备上**（见第 4 节）。
> 没装 Python/Node 时，终端会提示 command not found，这属正常。

### ④ 用终端
- 点 **🖥** 打开底部终端，在 `$` 后面敲命令，点 **↵** 提交。
- 终端是**真 shell**：有 Root 时走 `su`，没有则走普通 shell。
- 常用：
  ```sh
  ls /sdcard/PocketCodeStudio/workspaces
  python3 --version
  pwd
  ```

## 3. 项目配置（进阶）

想让某个项目用自定义命令运行，可在项目目录放 `.pcs/run.json`：

```json
{
  "language": "python",
  "entry": "main.py",
  "run": "python3 {entry}",
  "build": null,
  "output": null,
  "env": { "PYTHONUNBUFFERED": "1" }
}
```

- 占位符：`{entry}`=入口文件名、`{file}`=绝对路径、`{out}`=编译产物路径。
- `build`：编译命令（如 C/C++），运行时先跑它。
- 没有该文件时，App 按后缀自动生成默认配置。

## 4. 运行时与工具链

App 自带的是「壳 + 终端」，**具体语言运行时需要设备上存在**。三条获取途径：

1. **宿主机已有**：某些机型自带 `python`/`sh`，可直接用。
2. **通过终端安装**（需 Root，推荐）：
   ```sh
   # 例：Debian 系容器内
   apt update && apt install -y python3 nodejs gcc g++ golang cargo
   ```
3. **proot 发行版**（规划中）：后续版本将提供图形化「安装 Ubuntu/Debian」入口。

> 目前若终端报 `command not found`，说明该运行时尚未安装，按上面第 2/3 条补齐即可。

## 5. Root 权限

- App 通过 **libsu** 申请 Root。首次运行输入命令时，系统（Magisk/KernelSU 等）会弹出授权框，允许即可。
- 已授权后，顶栏右侧出现 **🔒 Root** 标记，状态栏显示「Root 已授权」。
- 未授权时为「普通模式」，命令降级到普通 shell，**依然能编辑文件**，只是不能做系统级操作（如 `mount`、改 `/system`）。
- 典型 Root 用法：
  ```sh
  mount -o rw,remount /          # 挂载可写
  cat /system/etc/hosts          # 读系统文件
  pm list packages               # 列应用
  ```

## 6. 插件系统

- 支持 **JS 插件**（基于 QuickJS 引擎）。插件可调用宿主提供的 API：
  `editorGet` / `editorSet`（读写编辑器内容）、`registerCommand`（注册命令）、
  `toast`（弹提示）、`log`（打日志）。
- 插件市场与图形化安装界面**尚在规划中**；当前版本以引擎能力为主。

## 7. 常见问题（FAQ）

**Q：点运行没反应 / 提示 PTY 不可用？**
A：说明内置终端 PTY 未就绪。确认安装的是完整 APK（含 `libpcs_term.so`），或重启 App 再试。

**Q：文件树是空的？**
A：工作区 `/sdcard/PocketCodeStudio/workspaces` 里还没文件。用文件管理器放一个进去。

**Q：能编译出 APK 吗？**
A：可以，但完整 Android 构建需要较重的工具链（aapt2/d8/gradle），目前建议在终端里用 `gradle` 命令配合联网环境执行；手机本地直接产出 APK 受 CPU 架构限制，通常需借助云端 runner。

**Q：数据存在哪？**
A：全部在 `/sdcard/PocketCodeStudio/`。卸载 App 不会删除，可放心。
