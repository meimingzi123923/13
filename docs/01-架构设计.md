# 01 · 架构设计

## 1. 整体分层

```
┌─────────────────────────────────────────────────────────┐
│                      UI Layer (Jetpack Compose)          │
│  EditorScreen · FileTreePanel · TerminalPanel ·          │
│  PluginPanel · SettingsScreen                            │
├─────────────────────────────────────────────────────────┤
│                     ViewModel / State                    │
│  EditorViewModel · TerminalViewModel · PluginViewModel   │
├─────────────────────────────────────────────────────────┤
│                       Core Services                      │
│  ┌──────────┐ ┌──────────┐ ┌──────────┐ ┌─────────────┐  │
│  │ Editor   │ │ Terminal │ │ Build/   │ │ Plugin      │  │
│  │ Service  │ │ Service  │ │ Run Svc  │ │ Manager     │  │
│  └──────────┘ └──────────┘ └──────────┘ └─────────────┘  │
│  ┌──────────┐ ┌──────────┐ ┌──────────┐ ┌─────────────┐  │
│  │ FS       │ │ Root     │ │ Package  │ │ Task/LSP    │  │
```

## 2. 核心数据流

### 2.1 编辑 → 运行
```
用户输入 ──▶ EditorService(语法高亮/补全)
              │  保存
              ▼
          FS Service ──▶ 项目目录 /sdcard/PocketCodeStudio/workspaces/<proj>/
              │  运行请求
              ▼
          Build/Run Service ──选择运行时──▶ Terminal Service
              │                                    │
              │                              创建 PTY 进程
              │                                    │
              ▼                                    ▼
       输出(日志/错误) ◀──── stdout/stderr ──── 子进程
```

### 2.2 插件加载
```
启动 ──▶ PluginManager.scan(plugins/)
           ├── .jar/.dex ──▶ DexClassLoader 加载 ──▶ 主线程注入 UI
           └── .js        ──▶ QuickJS 沙箱执行 ──▶ 调用 Host API
```

## 3. 关键线程模型

| 任务 | 所在线程 | 说明 |
|------|----------|------|
| UI 渲染 | Main | Compose |
| 文件读写 | IO Dispatcher | `Dispatchers.IO` |
| 语法分析/补全 | Default Dispatcher | 后台计算 |
| PTY 读取 | 独立线程池 | 阻塞读，事件流回 UI |
| 构建/编译 | 独立进程 | 避免拖垮 App 进程 |
| 插件执行 | 沙箱线程 | 插件崩溃不影响主程序 |

## 4. 进程与沙箱

- **编辑器 & UI**：运行在主 App 进程。
- **终端/工具链**：直接在本机 **原生执行**（无 proot、无 rootfs）。C/C++ 由 `NativeToolchain` 释放内置 clang，App 通过 JNI PTY 桥接。
- **插件**：运行在**独立线程 + 独立 ClassLoader**；JS 插件运行在 QuickJS 沙箱，超时强制终止。
- **Root 操作**：通过 `libsu` 的 `Shell.cmd("su -c ...")`，权限失败自动降级并提示。

## 5. 项目/工作区模型

```
/sdcard/PocketCodeStudio/
├── workspaces/            # 用户项目
│   └── <project-name>/
│       ├── .pcs/          # 项目元数据（任务、运行配置）
│       │   ├── run.json   # 运行配置
│       │   └── tasks.json # 构建任务
│       └── src/…
├── plugins/               # 已安装插件
├── runtimes/              # 用户自备运行时（python/node/go 等）
└── cache/                 # 包缓存、索引
```

`.pcs/run.json` 示例：
```json
{
  "language": "python",
  "entry": "src/main.py",
  "run": "python3 {entry}",
  "build": null,
  "env": { "PYTHONPATH": "src" }
}
```

## 6. 与外部世界的接口

- **包管理**：终端里直接 `pip install` / `npm i` / `cargo add`。
- **Git**：内置 `git`，支持 clone/commit/push + 轻量 UI。
- **网络**：用系统 `HttpURLConnection`/OkHttp 下载工具链，带断点续传。
- **分享/导入**：通过 `Intent` 接收外部文件与代码片段。
